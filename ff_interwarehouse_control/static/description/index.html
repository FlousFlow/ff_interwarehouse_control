Inter-Warehouse Control

Inter-warehouse transfers through lane transit locations + real per-warehouse user security for Odoo 18 Community

Production-ready Odoo 18 Community module to manage transfers between warehouses and to isolate stock users by warehouse using ACL + ir.rule (real security, not view domains).

Key features

  • Directed lanes: Cairo → Alexandria ≠ Alexandria → Cairo.
  • Lane-specific transit location: A/Stock → Transit A→B → B/Stock.
  • Clear audit trail: Requested / Dispatched / Received / Pending Dispatch / In Transit.
  • Standard Odoo backorders for partial dispatch and partial receipt.
  • No silent quantity changes - no automatic scrap or return.
  • Real warehouse security with ir.rule (stock.warehouse, location, quant, picking, move, move.line, picking.type, scrap).
  • Warehouse-scoped product quantities on the product form (qty_available, free_qty, incoming, outgoing, virtual).
  • Fail-closed: empty allowed list = no warehouse stock visible.
  • Multi-company safe and idempotent automatic warehouse setup.
  • Global Warehouse Manager bypass group.

Installation

Copy ff_interwarehouse_control into your addons path, restart Odoo and install the module. On install the module discovers all existing warehouses and creates every missing lane and operation type (idempotent).

Usage

  • Send: Inventory → Operations → Inter-Warehouse Transfers → New → choose lane → add products → Confirm → validate the dispatch picking.
  • Receive: the destination user validates the automatically-created receipt picking. Partial receipt creates a standard backorder.
  • Difference: Return to Source, or Resolve Difference (scrap) for the manager.
  • Restrict a user: Settings → Users → user → Warehouse Access → enable restriction and select allowed warehouses (managers only).
